# ترم‌یار | TermYar 🎓
> دستیار دانشگاهی و بازارچه دانشجویی خوابگاهی با سبک طراحی الهام‌گرفته از Remote.com

---

## ⚡ نحوه اجرای آسان در ویندوز (بدون خطا یا صفحه سفید)

اگر فایل زیپ پروژه را دانلود کرده‌اید، توجه فرمایید:

### ⚠️ نکته بسیار مهم:
پروژه را **ابتدا از حالت زیپ استخراج (Extract All) کنید**. اگر فایل‌ها را مستقیماً از داخل فایل زیپ موقت باز کنید، مرورگر ویندوز قادر به بارگذاری منابع نخواهد بود و صفحه سفید نمایش داده می‌شود.

### روش‌های اجرا بعد از Extract کردن:

1. **روش اول (فوری و بدون نیاز به نصب هیچ چیز):**
   - روی فایل **`اجرای_مستقیم_ترم‌یار.html`** یا **`TermYar.html`** یا **`dist/index.html`** دابل‌کلیک کنید.
   - برنامه فوراً به صورت کامل و آفلاین در مرورگر شما باز می‌شود.

2. **روش دوم (با یک کلیک):**
   - روی فایل **`اجرای_ویندوز.bat`** یا **`run.bat`** دابل‌کلیک کنید.

3. **روش سوم (توسعه‌دهندگان با Node.js):**
   - در پوشه پروژه ترمینال یا CMD را باز کرده و دستور زیر را اجرا کنید:
     ```bash
     npm run dev
     ```
   - سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.
