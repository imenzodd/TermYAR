# ترم‌یار — بازطراحی داشبورد

این نسخه، رابط ترم‌یار را با الهام از تصویر ارسالی بازطراحی می‌کند: نوار کناری، کارت‌های آمار، تقویم هفتگی، دستیار، پیشرفت، وظایف امروز و پروژه‌ها.

## اجرا در ویندوز
1. ZIP را استخراج کنید.
2. فایل `index.html` را در Chrome یا Edge باز کنید. برای بهترین تجربه می‌توانید پوشه را در VS Code باز کرده و با افزونه Live Server اجرا کنید.

## قابلیت‌ها
- رابط فارسی و راست‌چین واکنش‌گرا
- تقویم هفتگی با تاریخ‌های شمسی در مرورگرهای جدید
- افزودن کار/پروژه/امتحان با تاریخ شمسی، ساعت و اولویت
- ذخیرهٔ کارها و تنظیمات در مرورگر با `localStorage`
- انتخاب فوری و ماندگار چهار پس‌زمینه
- صفحات نمونهٔ دروس، امتحانات، مطالعه گروهی و گزارش‌ها

## محدودیت‌ها
این یک فرانت‌اند نمونه است. ورود واقعی، همگام‌سازی ابری، اتاق مطالعهٔ چندکاربره، اعلان واقعی و هوش مصنوعی متصل به سرویس هنوز پیاده‌سازی نشده‌اند. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در صورت آفلاین بودن، فونت جایگزین استفاده خواهد شد.
